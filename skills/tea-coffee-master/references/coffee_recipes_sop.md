# 精品咖啡与商用特调爆款配方及萃取SOP

---

## 一、 意式浓缩咖啡 (Espresso) 商用萃取标准

意式浓缩是所有拿铁、特调与美式咖啡的心脏。商用出品必须每日早晨进行**校磨与品控测试**：

| 参数项目 | 行业标准商用基准 | 异常偏离调整指南 |
| :--- | :--- | :--- |
| **咖啡粉重 (In)** | 18.0g ~ 20.0g (双份手柄粉碗) | 称重误差必须控制在 ±0.2g 以内，避免流速波动。 |
| **萃取液重 (Out)** | 36.0g ~ 40.0g (常规粉液比 1:2) | 深烘焙豆可缩短至 1:1.8 (约34g)，浅中烘焙可拉长至 1:2.2 (约42g)。 |
| **萃取时间 (Time)** | 25 秒 ~ 28 秒 | **流速过快 (<22s)**：萃取不足，酸涩薄弱。需调细研磨或增加粉量。<br>**流速过慢 (>32s)**：过度萃取，焦苦发涩。需调粗研磨或减少粉量。 |
| **萃取水温** | 92℃ ~ 93.5℃ | 水温过高易焦苦；水温过低酸味尖锐。 |
| **萃取水压** | 9 bar (恒压) | 检查泵压表，粉饼压实需水平平整无通道效应。 |
| **Crema (咖啡脂)** | 浅褐红带有金黄斑纹，厚度约占杯体 1/5，质地致密不易散。 |

## 二、 经典意式奶咖出品规范 (奶泡与温控)

打发牛奶的关键是**发泡与融合**两步：
- 蒸汽喷嘴入液面 0.5cm，斜 45 度角引入微气泡（进气约 3~5 秒）。
- 随后下沉喷嘴至液面下 1cm 形成剧烈旋涡，打碎粗泡，使奶液呈如丝绸般反光的微泡沫（Microfoam）。
- **终点温度必须控制在 58℃~65℃**（超过 70℃ 乳清蛋白变性，甜感丧失并产生水味）。

| 单品名称 | 规格容量 | 浓缩咖啡 (Espresso) | 蒸热全脂鲜牛奶 | 奶泡厚度要求 |
| :--- | :--- | :--- | :--- | :--- |
| **经典拿铁 (Caffe Latte)** | 350ml | 双份浓缩 (38g) | 约 240ml 鲜奶 | 奶泡厚度约 **0.8cm ~ 1.0cm**，口感丝滑轻盈。 |
| **澳白 / 馥芮白 (Flat White)** | 220ml ~ 250ml | 双份精粹浓缩 (Ristretto 30g) | 约 160ml 鲜奶 | 奶泡厚度极薄 **0.3cm ~ 0.5cm**，突出深沉咖啡醇厚度。 |
| **经典卡布奇诺 (Cappuccino)** | 200ml ~ 220ml | 双份浓缩 (36g) | 约 120ml 鲜奶 | 奶泡厚度 **1.5cm ~ 2.0cm**，棉花糖般浓密厚实。 |

## 三、 商业爆款特调果咖与乳咖配方

### 1. 【全网销冠】生椰拿铁 (Raw Coconut Latte)
- **客群画像**：几乎不挑人的爆款单品，抗苦利器，外卖回购之王。
- **容量规格**：450ml ~ 500ml 冰饮杯
- **核心物料配比**：
  - 优质特调生椰乳（推荐：菲诺生椰乳）：180 ml
  - 双份深烘拼配意式浓缩：38 ml ~ 40 ml
  - 机制冰块：180 g
  - *可选增香*：少许全脂牛奶 20ml（若想削弱生椰油腻感，增加清爽度）
- **出品 SOP**：
  1. 冰杯中先注入 180ml 菲诺生椰乳。
  2. 铲入 180g 满杯冰块，使冰块露出液面约 1cm。
  3. 现场萃取双份浓缩咖啡。
  4. 沿最高处的一块冰块顶部缓慢淋下浓缩，形成清晰的**黑白渐变撞色分层**。
  5. 贴标封口出杯，提醒顾客：“饮用前请充分搅拌均匀”。

### 2. 【视觉与口感冲击】冰博克 Dirty (脏咖啡)
- **风味特征**：上热下极冰，第一口苦香撞击冰甜奶酪感，随后层层交融。
- **出品规格**：200ml 厚底玻璃杯 / 高透专用短杯（**绝对不加冰块**）
- **核心物料配比**：
  - 提前深度冰镇的提纯厚乳（如冰博克提纯奶或厚牛乳）：120 ml
  - 新鲜萃取的双份深烘浓缩 (超短精粹 Ristretto)：30 ml
- **出品 SOP**：
  1. 出品杯需提前置于冷冻柜冷藏至杯身结白霜。
  2. 往冰杯中注入 120ml 冰透的厚牛乳（奶温控制在 2℃~4℃）。
  3. 直接将杯子接在咖啡机冲煮头下方，将两股高温（90℃+）浓缩咖啡直接倾泻落入冰奶液面中央。
  4. 浓缩咖啡因油脂与温度差异在奶层上方缓缓向下渗透形成棕色污渍状（Dirty）。
  5. **黄金食用期为出杯后 3 分钟内**，必须大口大口吞咽饮用，感受温差与浓缩爆裂感。

### 3. 【清爽高毛利】鲜榨橙C美式 (Iced Orange Americano)
- **客群画像**：健身减脂控糖白领、春夏下午茶第一选择。
- **容量规格**：500ml 冰杯
- **核心物料配比**：
  - 100% 鲜榨甜橙汁 / NFC 非还原橙汁：160 ml
  - 双份中深烘浓缩咖啡：38 ml
  - 食用冰块：180 g
  - 新鲜香橙切片：1 片（贴杯壁装饰）
  - 纯净水/苏打水：40 ml（若需更清爽可加苏打气泡）
- **出品 SOP**：
  1. 客用杯壁贴上一片新鲜香橙片。
  2. 倒入 160ml NFC 橙汁与 40ml 直饮冷水/气泡水，搅拌均匀。
  3. 加入 180g 冰块直至杯顶。
  4. 缓缓浇入双份意式浓缩，形成鲜艳金黄与醇黑咖啡分层。

### 4. 【燕麦谷物香】大师级燕麦拿铁 (Oat Milk Latte)
- **容量规格**：450ml 冰饮 / 350ml 热饮
- **核心物料配比**：
  - Oatly 咖啡大师专供燕麦奶：200 ml
  - 双份中深烘意式浓缩：38 ml
  - 冰块：160 g（热饮免冰）
  - *可选提味*：香草风味糖浆 8g 或 肉桂粉少许
- **出品 SOP**：
  - *冰饮*：杯中加入冰块、燕麦奶，顶部浇入双份浓缩。
  - *热饮*：将燕麦奶蒸发至 60℃（燕麦奶打泡进气需比牛奶稍少，防止泡沫过粗），直接进行压纹拉花。

## 四、 批量商用冷萃咖啡 (Cold Brew) 浸泡 SOP

- **粉水比例**：1 : 10（即 100g 粗研磨咖啡粉配 1000ml 直饮冷水）。
- **研磨刻度**：粗研磨（如粗海盐/法压壶刻度，避免细粉过多导致浑浊）。
- **浸泡工艺**：
  1. 将咖啡粉装入商用专用食品级冷萃无纺布滤袋中，扎紧袋口。
  2. 放入密封冷萃桶，注入纯净直饮冷水，上下翻动几次使咖啡粉充分浸润。
  3. 盖紧密封桶盖，放入 4℃~6℃ 商业冷藏柜中**低温冷萃浸泡 16~18 小时**。
  4. 捞出滤袋彻底沥干（切勿用力挤压防止苦涩残渣析出）。
  5. 用细目滤纸进行二次澄清过滤，分装至高透玻璃密封瓶中冷藏，风味保鲜期可达 5~7 天。
  6. 出品时按原液 150ml + 冰块 150g 直饮，亦可调入青柠片或汤力水制作气泡冷萃。
